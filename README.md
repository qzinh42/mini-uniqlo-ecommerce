# Mini Uniqlo — Đồ án E-commerce Full-stack

Trang web thương mại điện tử mini lấy cảm hứng từ Uniqlo, xây dựng làm đồ án học phần CNTT.

## Công nghệ sử dụng
- **Frontend:** HTML, CSS, JavaScript thuần
- **Backend:** Spring Boot (Java), REST API
- **Database:** Microsoft SQL Server

## Chức năng chính
- Xem/lọc/tìm kiếm sản phẩm theo danh mục
- Giỏ hàng, đặt hàng, xem lịch sử đơn hàng
- Đăng ký/đăng nhập, phân quyền user/admin
- Trang quản trị: thêm/sửa/xóa sản phẩm
- Sản phẩm yêu thích theo tài khoản
- Khung chat hỗ trợ khách hàng

## Cách chạy dự án
1. Backend: mở folder `backend/` bằng IDE hỗ trợ Maven, cấu hình `application.properties` với thông tin SQL Server của bạn, chạy `mvnw spring-boot:run`.
2. Frontend: mở folder `frontend/` bằng VSCode + extension Live Server, mở `index.html`."# mini-uniqlo-ecommerce"
